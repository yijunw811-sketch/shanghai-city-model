# 设计地块与区域的协同改善方向

以下是36张既有专题图的综合研究判断；空间统计详见reports/spatial_evidence.json，逐图说明详见MAP_ANALYSIS_NOTES.md。建议不能替代现况、权属、容量及工程条件核查。

| 研究重点 | 地块与区域的证据关系 | 协调改善方向 |
|---|---|---|
| 建筑密集界面与开敞空间 | 地块基底覆盖26.6%，全域22.6%；按原图分级，触及地块的100米单元中≥45%部分约占地块11.0% | 以密集单元的院落、消防和人行界面核查为先；沿江场西路、万荣路衔接相邻街区，研究合法开放的空间与入口整合，不全区统一减量或增量。 |
| 公交—街道—入口的连续接入 | 5分钟公交接入已覆盖地块83.3%的映射步行路段，基础相对较好；高架与主路仍有不同层级 | 从公交节点、过街到实际入口统筹“最后一段”，核查地面层与高架界面的安全、门禁、无障碍及后勤。密度和接近度不等于通行品质。 |
| 日常服务与功能互补 | 地块功能依据覆盖21.2%，全域52.3%；服务15分钟可达路段约10.1%，但全域日常服务观察点仅29条 | 先核对已有店铺、服务、容量与营业时间，区分真实短缺与记录遗漏；沿公共路径配置经需求证实的互补服务，不在红线内重复周边全部功能。 |
| 蓝绿资源与街区共享 | 地块已映射绿地6.6%、水面6.8%，高于全域同口径；近邻有半里绿廊、彭浦公园和青年体育公园等资源 | 核查真实开放入口与岸线条件，把地块水绿界面、遮荫步道和相邻街道串联；重点在可用性、连续性与季相质量，不能把映射面积直接当公共供给或生态质量。 |
| 邻近居民与设施协同 | 2020历史人口模型显示周边环带密度高于地块；地块有周边教育资源的网络接入，不能仅凭内部教育点为空判定缺校 | 用现况人口、活动、学校容量与校门调查核实需求，考虑地块公共空间对周边人群的开放贡献，协调通学和日常活动路线。两期人口产品不解释增长趋势。 |
| 热环境与全天候使用 | 夏季单景地表温度地块48.6℃、全域49.6℃，不支持“地块整体更热”；冬夏NDVI信号均低于周边 | 以实际步行路径和使用时段测量遮荫、辐射、风及冬季采光，安排适地树冠、休憩与铺装优化；不按单景温度或指数直接给出种植/工程指标。 |
| 数据冲突与跨边界实施 | 地块有15处源端点、2处路建叠置复核记录；历史水面产品与现状矢量水面也存在明显差异 | 建立可定位的现场台账，分清门禁、分层、估宽和数据遗漏；跨红线共同核查后再定通行与滨水方案。粗DSM和示意坡度不作为排水工程依据。 |

实施顺序宜为：先核对权属与真实入口、关键通行和现状需求；再选择能够同时改善地块与邻街的连续步行、遮荫及共享节点；最后依据实际容量、运营、投入与使用反馈深化建设规模和分期。当前没有依据确认任何新增道路、具体控高、学校规模或法定用地变更。
