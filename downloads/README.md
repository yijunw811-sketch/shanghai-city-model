# 上海城市模型成果下载

[下载第二版 ZIP（约 13.2 MB）](./shanghai-city-model-delivery-v2.zip?raw=true)

如果 GitHub 文件页面不直接下载，请点击文件页面的 **Download raw file**。私人仓库需要先登录有访问权限的 GitHub 账号。

成果包含 GeoPackage、全域/分层/28个瓦片 GLB、可编辑 Blender 工程、四张 PNG、自动化脚本、原始 OSM 缓存和质量报告。解压后先阅读 `outputs/使用说明.md`、`outputs/更新记录.md` 和 `outputs/reports/QA.md`。完整性校验见本目录 `SHA256SUMS.txt`。

边界面积约22.0091平方公里；第二版有1731个地上建筑体块、1596条道路中心线及道路面，补入映射河渠面段和19个树点。35个GLB和Blender工程已读回验证。

这是有来源依据的模型初版，城市要素完整性仍受OSM覆盖限制。建筑高度、部分道路宽度、河渠宽度和树冠尺寸含明确标记的估计；桥隧高程为示意，其中9段示意坡度异常已列入QA，不能作为实测纵坡。没有DEM，基底不是实测地形。未在SketchUp 2025中进行原生导入测试。
